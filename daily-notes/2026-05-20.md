# AI Agent × Hermes 学习笔记｜Day 2

## 今日学习主题

今天主要学习了：

- AI Agent 的核心概念
- AI 从"问答模型"到"任务执行模型"的变化
- 聊天机器人与 Agent 的区别
- AI IDE 的作用
- Hermes Agent 的核心运行机制
- Hermes Agent 的能力结构

整体上开始真正理解：

AI 正在从"告诉人怎么做"，逐渐进化成"直接帮人完成任务"。

---

# 一、AI 的进化：从问答到任务执行

传统 AI 的核心模式主要是：

"问答交互"。

用户提出问题后，

AI 返回：

- 解释
- 建议
- 文案
- 代码
- 总结

这类 AI 更像是：

一个非常聪明的聊天助手。

它主要负责：

"告诉你应该怎么做"。

典型场景包括：

- 解释代码
- 总结文章
- 写文案
- 回答问题

但新的 AI Agent 模式已经开始变化。

现在 AI 不只是回答问题，

而是开始：

"直接执行任务"。

新的核心模式属于：

任务执行型 AI。

它可以：

- 创建文件
- 自动运行代码
- 修复 Bug
- 读取项目
- 操作工具

因此：

AI 的定位正在从"聊天工具"

转向：

"行动型智能体"。

（AI Agent：能够自主完成任务的 AI 系统。任务执行：AI 不只是回答问题，而是真正完成操作。Bug：程序中的错误或问题。）

---

# 二、聊天机器人与 Agent 的本质区别

聊天机器人本质上仍然属于：

"信息回答系统"。

用户输入问题后，

AI 会返回：

- 说明文档
- 安装教程
- 配置步骤
- 文字解释

也就是说：

聊天机器人主要负责：

"告诉用户如何做"。

例如：

用户问：

"怎么配置环境？"

聊天机器人会返回：

- 下载地址
- 安装步骤
- 配置方法

但 Agent 的目标并不是"告诉你"。

而是：

"直接帮你完成"。

用户只需要提出需求，

Agent 就会：

- 自动调用命令
- 自动安装环境
- 自动配置项目
- 自动执行任务

因此：

聊天机器人更偏向：

"知识回答"。

而 Agent 更偏向：

"行动执行"。

（环境配置：安装并设置项目运行所需的软件环境。命令：让计算机执行任务的指令。智能体：能够自主执行任务的程序。）

---

# 三、聊天型 AI 与 AI IDE

目前最常见的 AI 工具主要可以分成两类。

第一类是：

聊天型 AI。

代表工具包括：

- ChatGPT
- Claude
- Gemini
- DeepSeek

这类工具主要负责：

- 对话
- 写作
- 翻译
- 代码解释
- 文案整理

但它们通常无法真正操作本地电脑环境。

第二类则是：

AI 编程助手 / AI IDE。

代表工具包括：

- Cursor
- GitHub Copilot
- Windsurf
- Trae

这类工具的核心能力在于：

它们直接集成到开发环境中。

不仅能够生成代码，

还能够：

- 修改项目
- 理解代码结构
- 自动修复 Bug
- 操作整个工程

因此：

AI IDE 本质上是：

"集成了 AI 的开发工具"。

（IDE：集成开发环境，用于编写和运行代码的软件。GitHub Copilot：GitHub 推出的 AI 编程助手。代码结构：项目内部代码之间的组织方式。）

---

# 四、AI Agent 的核心运行机制

AI Agent 的运行并不是一次性完成任务，

而是一个不断循环的过程。

整个流程通常包括：

1. 理解目标
2. 调用工具
3. 观察结果
4. 修正执行

Agent 首先会理解用户目标，

然后决定：

应该调用哪些工具。

执行完成后，

它还会观察结果是否正确。

如果发现错误，

则会继续调整方案并重新执行。

因此：

AI Agent 更像是：

一个能够"边做边调整"的自动化系统。

而不是传统的一问一答机器人。

这也是为什么 Agent 比普通聊天 AI 更接近真正的"自动工作流"。

（工作流：任务按照固定步骤自动执行的流程。调用工具：AI 使用外部能力完成任务。自动调整：发现错误后自动修复。）

---

# 五、Hermes Agent 的核心能力

Hermes Agent 属于一种典型的 AI Agent 系统。

它的核心能力主要包括：

多模型支持。

也就是说：

Hermes 可以同时接入多个 AI 模型完成任务。

例如：

- Claude
- OpenAI
- Gemini

等不同模型。

Hermes 还具备：

工具调用能力。

它能够：

- 读取文件
- 搜索网页
- 调用外部工具

因此：

Hermes 不只是"聊天"。

而是真正具备：

"操作能力"。

Hermes 还具备：

Memory 记忆能力。

它能够记录：

- 历史任务
- 工作状态
- 上下文信息

从而保持任务连续性。

除此之外，

Hermes 还拥有：

Skills 技能系统。

技能本质上属于：

可重复执行的任务流程。

Hermes 可以不断复用这些流程提高效率。

最后：

Hermes 还支持 Gateway 消息网关。

它能够直接接入：

- Telegram
- 消息系统
- 外部通知渠道

实现自动通信。

（多模型支持：同时使用多个 AI 模型。Memory：AI 保存上下文信息的能力。Skills：可重复调用的任务流程。Gateway：连接不同系统的通信入口。Telegram：即时通信平台。）
