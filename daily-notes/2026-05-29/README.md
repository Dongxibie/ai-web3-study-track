# Community

* 加入垂直社区比泛社交更有效。

  * 垂直社区（Vertical Community）：围绕特定领域建立的社区，例如 AI、DeFi、Solana。

* 社区成员之间更容易建立信任与连接。

* 在线社区可以降低地域限制。

  * Remote：远程协作模式。

* 本地 Meetup 适合建立初始人脉。

  * Meetup：线下交流活动。

* 不确定结果时仍然应该参与活动。

* Meetup 可能带来：

  * 合作者
  * 工作机会
  * 投资人
  * 长期人脉

* Web3 社区高度依赖线上协作。

# Fellowship / Accelerator

* Fellowship 提供结构化学习与社交网络。

  * Fellowship：长期培养计划，通常包含导师、课程与项目实践。

* Accelerator 用于帮助项目快速成长。

  * Accelerator：创业加速器。

* Fellowship 通常包含：

  * 项目实践
  * 导师体系
  * 社区支持
  * Demo 展示

* 加入 Fellowship 前通常需要一定背景或项目经历。

* Academy → Hackathon → Accelerator 是常见成长路径。

* Local Chapter 可以扩展全球社区。

  * Local Chapter：地区分部。

# Networking

* 有共同社区背景时，Cold DM 回复率更高。

  * Cold DM：向陌生人发送私信。

* GitHub 与社区记录可以提高可信度。

* Discord Ticket 可以作为联系项目方的方法。

  * Discord Ticket：Discord 社区中的工单系统。

* Networking with Context 更容易建立联系。

  * 指拥有共同背景、社区或项目时的社交。

* 从本地社区开始建立影响力，再扩展到国际社区。

# Open Source

* Open Source 是进入 Web3 的重要入口。

  * Open Source：开源项目。

* Open Source Contribution 可以建立长期技术记录。

  * Contribution：贡献记录。

* Recruiter 更关注 GitHub 而非 LinkedIn。

  * Recruiter：招聘人员。

* 开源贡献可以帮助：

  * 获得 Fellowship
  * 获得工作机会
  * 获得项目合作机会

* 对于不擅长社交的人：

  * Open Source 是低压力参与方式。

* 持续贡献特定生态可以建立个人定位。

# Personal Branding

* Build in Public 可以提高曝光度。

  * Build in Public：公开分享构建过程。

* 持续发布内容可以建立行业影响力。

* X 与 LinkedIn 是主要平台。

  * X：Twitter。
  * LinkedIn：职业社交平台。

* Ambassador Program 可以提高可信度。

  * Ambassador Program：项目官方推广计划。

* Ambassador 身份可以帮助：

  * 获得合作机会
  * 建立行业连接
  * 获得工作机会

* 加入低质量项目可能损害信誉。

# AI + Web3

* AI + Web3 被认为比单纯 AI 更具长期潜力。

* AI 可以提升 Builder 开发效率。

* Web3 提供更开放的构建环境。

* Agent 可能成为未来 Web3 的主要用户。

  * Agent：具备自动执行能力的 AI 系统。

* AI Agent + On-chain 是潜在方向。

  * On-chain：链上运行。

* Web3 减少对封闭平台的依赖。

  * Closed Source：闭源系统。

# Builder Strategy

* 先加入社区，再开始构建项目。

* 从小项目开始积累。

* 公开展示项目可以提高机会获取概率。

* 成为 Speaker 可以增加可信度。

  * Speaker：公开分享者。

* Mentor 身份有助于扩大行业连接。

  * Mentor：导师。

* Local Influence → Global Opportunity 是常见路径。
